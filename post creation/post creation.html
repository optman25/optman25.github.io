점검 내역 작성

점검 내역을 작성할 수 있습니다. 점검 내역은 건물의 각 호실에 포함된 옵션에 대한 점검 항목과 점검 값의 목록을 기반으로 작성됩니다. 점검 내역 작성 화면에서는 각 호실에 포함된 옵션의 점검 항목과 점검 값의 목록이 표시되며, 사용자는 각 항목에 대해 점검 결과를 입력하고 저장할 수 있습니다. (각 옵션의 점검 항목과 점검 값 목록의 설정은 건물 상세 정보 설정 화면에서 이루어짐)

점검 내역 작성은 다음과 같은 순서로 진행됩니다.

  1. 홈 화면 또는 달력 화면의 중앙에 있는 '+' 버튼을 클릭하여 '점검 내역 작성' 화면으로 이동합니다.
  2. 점검 내역을 작성할 호실을 선택합니다. 호실을 선택하면 해당 호실의 옵션을 선택할 수 있습니다.
  3. 옵션 목록에서 해당 옵션을 선택합니다.
  4. 옵션을 선택하면 옵션에 대한 점검 항목과 점검 내용 입력 창이 표시됩니다. 직접 점검 내용을 입력합니다. 점검 값의 목록이 표시되는 경우에는 해당 값을 선택합니다. 날짜와 시간을 입력하는 경우에는 해당 창을 클릭하여 날짜와 시간 입력 창을 표시하고, 날짜를 선택하고 시간을 입력합니다.
  5. 필요한 경우, 추가적인 메모를 입력할 수 있습니다. 또한, 상단의 카메라 버튼을 클릭하여 사진을 촬영하거나, 갤러리에서 사진을 선택하여 점검 내역에 첨부할 수 있습니다.
  6. 모든 점검 결과를 입력한 후, 상단의 '저장' 버튼을 클릭하여 점검 내역을 저장합니다.

점검 내역 작성 결과로 홈 화면에 추가된 점검 내역이 표시됩니다.
