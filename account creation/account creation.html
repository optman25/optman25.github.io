계정 생성 - 상세

계정 생성은 앱을 사용하기 위해 필요한 첫 단계입니다. 계정을 생성하면 로그인하여 앱의 다양한 기능을 이용할 수 있습니다.

계정 생성 과정은 다음과 같은 단계로 이루어집니다.

  1. 옵션관리 101 앱 설치

    2. 앱 스토어에서 '옵션관리 101' 앱을 검색하여 설치합니다. 설치가 완료되면 앱을 실행합니다.

  2. 앱 실행

    3. 앱을 처음 실행하면 회원가입/로그인 화면이 표시됩니다.

  3. 개인 정보 입력

    4. 이메일 주소, 비밀번호 등 필요한 개인 정보를 입력합니다. 모든 필드는 필수 입력 사항입니다. 이메일 주소는 정당한 형식이어야 하며, 비밀번호는 문자 또는 숫자로 이루어져야 하며 최소 6자 이상이어야 합니다. 입력이 완료되면 '이메일 회원 가입' 버튼을 클릭합니다.

계정 생성이 완료되면 로그인 화면(계정 생성 화면과 동일)에서, 입력한 이메일 주소와 비밀번호를 사용하여 로그인할 수 있습니다.

  • 이메일 주소와 비밀번호로 로그인하는 대신 구글 계정으로 로그인을 원하는 경우, '구글 로그인' 버튼을 클릭합니다.
