기본 설정 - 상세

옵션 관리 앱을 사용하기 위해서는 먼저 기본 설정을 완료해야 합니다. 임대인과 임대 부동산의 기본적인 정보를 입력합니다. 기본 설정은 앱을 처음 사용할 때 한 번만 진행하면 됩니다.

  • 메뉴에서 '기본 설정' 클릭

    메뉴에서 '기본 설정'을 클릭합니다.

  • 기본 정보 입력

    기본 정보 입력 화면에서 임대인과 임대 부동산의 기본 정보를 입력합니다. 임대인의 이름, 임대 부동산의 건물 이름, 주소, 호실 갯수 등을 입력합니다.

  • 기본 설정 저장

    기본 정보 입력이 완료되면 우상단의 '저장' 버튼을 클릭하여 기본 정보를 저장합니다. 저장이 완료되면, '건물 상세 설정' 화면으로 이동합니다.

기본 설정을 완료하면, 건물에 대한 상세 설정이 가능합니다. 상세 설정이 완료되면, 사용자는 앱을 통해 옵션의 이력을 기록하고 관리할 수 있습니다.
